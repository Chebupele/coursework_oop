# Лабораторная работа 1

Супервизор управляет программой, работающей в отдельном потоке. Поток-демон случайно меняет её состояние. При STOPPING супервизор перезапускает программу, при FATAL_ERROR завершает её. Все переходы сохраняются в очереди, взаимодействие потоков построено на wait/notify.

Требуется JDK 17–24.

## Сборка и запуск

```powershell
.\gradlew.bat build
.\gradlew.bat run --args="500"
```

Аргумент — интервал изменения состояния в миллисекундах. По умолчанию 1000.

## Тесты

```powershell
.\gradlew.bat test
```

В IntelliJ IDEA откройте эту папку как Gradle-проект и запустите класс ru.oop.supervisor.Main. Аргумент задаётся в Program arguments.
