# ООП

Лабораторная работа и курсовая на Java с Gradle.

- [lab-1](lab-1) — супервизор программы с использованием потоков и wait/notify.
- [coursework](coursework) — многопоточный агрегатор REST API с сохранением в JSON и CSV.

Требуется JDK 17–24. Каждый проект открывается в IntelliJ IDEA отдельно как Gradle-проект. Gradle Wrapper включён.

Сборка и тесты из папки соответствующего проекта:

```powershell
.\gradlew.bat build
```

Подробности запуска находятся в README каждой работы. Консольный интерфейс — на английском языке.
